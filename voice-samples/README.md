# TRON robotic voice samples (DSP preview only)

These WAVs demonstrate the subtle `RoboticVoiceProcessor` coloration only.
They are **not** ElevenLabs / spoken-language samples.

Real English + Japanese spoken samples require:

1. `ELEVENLABS_API_KEY`
2. `TTS_ELEVENLABS_ENABLED=true`
3. Optional custom voice id via `TTS_ELEVENLABS_VOICE_ID`

Do not treat browser Web Speech as editable robotic audio.
